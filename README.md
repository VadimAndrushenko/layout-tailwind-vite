# Запуск проекта на базе Vite и Tailwind

Краткое описание

- Это статичная верстка выполненная на основе Vite и Tailwind
- Работа доступна в портфолио на https://kwork.ru/user/vadimandrusenko320

Как локально посмотреть проект

Вариант 1

```bash
git clone https://github.com/VadimAndrushenko/layout-tailwind-vite.git
```

Вариант 2

- Скачать zip архив и распаковать

Установка зависимостей

- Открыть терминал в папке проекта

```bash
npm install
```

Запуск проекта

- Для запуска проекта выполнить в терминале

```bash
npm run dev
```
