# Проект на базе Vite и Tailwind

Это проект со статичной версткой, выполненный на базе Vite и Tailwind CSS.  
Заказчик попросил реализовать только верстку без динамики.

Работа была выполнена на платформе Kwork.  
Портфолио доступно по ссылке  
https://kwork.ru/user/vadimandrusenko320

## Как локально запустить проект

### Способ 1. Клонирование репозитория

Откройте папку проекта в редакторе кода и выполните команду

```bash
git clone https://github.com/VadimAndrushenko/layout-tailwind-vite.git
Способ 2. Загрузка архива
Скачайте zip архив репозитория и распакуйте его на компьютере.

Установка зависимостей
Перейдите в папку проекта и выполните в терминале

bash
Копировать код
npm install
Запуск проекта
Для запуска проекта выполните команду

bash
Копировать код
npm run dev
